# Pavr Tools & Technologies — Design Context

## Design Context

### Users
**Primary audience**: Battery manufacturing companies — procurement leads, R&D engineers, and technical decision-makers evaluating battery component suppliers. Secondary: automotive OEM procurement, EV startup founders, and solar EPC companies.

**Context of use**: Desktop-first B2B research sessions. The buyer is evaluating battery component suppliers, comparing capabilities, and building a shortlist. They spend 5–15 minutes on the site during work hours, checking certifications, product specs, and the contact form. Trust and credibility signals matter more than entertainment.

**Job to be done**: Quickly validate that Pavr is a capable, ISO-certified, technically serious battery component and injection molding supplier worth contacting for a project quote.

### Brand Personality
*Expert. Reliable. Trusted.*

Pavr is the supplier that battery companies trust with their most critical components. The brand should feel like a firm handshake — confident, warm, without unnecessary showmanship. Engineering competence radiates through clarity, not decoration. Think Apple's confidence in presentation meets the industrial seriousness of a top-tier mold manufacturer.

### Aesthetic Direction
**Style**: Editorial Industrial — warm off-white surfaces, charcoal typography, copper/terracotta accent. Feels like a premium engineering catalog from a master craftsman's workshop.

**Color tokens**:
- Background: `#F5F2ED` (stone-50) — warm off-white, like workshop paper
- Surface: `#FFFFFF` for cards
- Dark hero sections: `#0D0C0A` (stone-950)
- Primary text: `#2B2825` (stone-700)
- Secondary text: `#6B6560` (stone-500)
- Accent: `#C45D2C` (copper-500) — burnt copper/terracotta
- Accent hover: `#A84B20` (copper-600)
- Secondary accent: `#5B8C6D` (sage-500) — for success states, checkmarks
- Borders: `#E5E0D9` (stone-200)

**Typography**:
- Display/headings: **Instrument Serif** — sharp, editorial, unexpected for manufacturing
- Body/UI: **DM Sans** — clean geometric, excellent readability
- Labels/code/specs: **JetBrains Mono** — engineering feel for technical data

**References**:
- **tdlmould.com** — Strong hero imagery with dark overlays, bold stat counters, structured card layouts with hover effects, gold accent on dark backgrounds. Takeaway: dramatic hero sections, clear capability showcase, bold typography hierarchy (800 weight headings).
- **Apple** — Restrained elegance, massive whitespace, product-focused, animations that serve comprehension. Takeaway: confidence through simplicity, one hero statement per section, let the product speak.
- Premium B2B SaaS (Linear, Vercel) for interaction quality.

**Anti-references**: Generic dark navy + amber AI templates; flashy animations that distract from content; overcrowded layouts with competing hierarchy; cheap-looking stock photography

**Theme**: Light-first. Hero sections use dark (`stone-950`) for contrast. All content sections use warm light backgrounds.

### Design Principles

1. **Credibility through clarity** — Every page element should build trust. Certifications, specs, process steps, and testimonials are features, not afterthoughts. Hierarchy serves comprehension, not aesthetics.

2. **Restraint is sophistication** — One accent color used sparingly signals taste. Rounded corners max 8px. No decorative shadows, no glows, no gradients on light sections. Let whitespace breathe.

3. **Motion serves function** — Animations exist to orient (stagger reveals), confirm (button press scale), or maintain context (page transitions). Never animate for decoration. All UI animations ≤ 300ms.

4. **Typography is the design** — Instrument Serif in headings creates character without needing complex visuals. Let font do the heavy lifting. Prose-first layout on content pages.

5. **Industrial warmth** — The palette evokes real materials: copper wire, workshop paper, machined steel. Avoid cold blues and sterile whites. The interface should feel tactile and grounded.

### Animation Tokens
- Easing: `cubic-bezier(0.16, 1, 0.3, 1)` (ease-out-expo) for entering elements
- Easing: `cubic-bezier(0.77, 0, 0.175, 1)` for moving elements
- UI transitions: 150–250ms
- Page transitions: 300ms
- Spring hover on cards: `stiffness: 400, damping: 28`
- Button press: `scale(0.97)` via `.btn-press` CSS class
- Reduced motion: respected via `@media (prefers-reduced-motion: reduce)`

### Tech Stack
- React 19 + Vite 8 + TailwindCSS 3 + Framer Motion 12
- lucide-react icons (stroke-based, consistent weight)
- Express + MongoDB (in-memory for dev, persistent for prod)
- Google Fonts: Instrument Serif, DM Sans, JetBrains Mono
